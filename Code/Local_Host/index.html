Text

The board wraps the text and, on "Largest that fits", picks the biggest size that fits inside the margin.

Images

Pick or drop any images (PNG, JPG, GIF, WebP…). They are resized here and sent to the screen.

A photo takes about 4 seconds over USB; a simple drawing with flat colors is much faster. With several files chosen, the preview shows the first one and "Add to gallery" adds them all.

Preview (exactly what the screen will show)

Gallery

Click a picture to show it. Play steps through them in order; set 0 to go as fast as the USB link allows. The gallery is kept in this browser.
